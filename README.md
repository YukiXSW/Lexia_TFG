## Ejecución Local

### **Requisitos Previos**
- **Node.js** 18.x o superior
- **pnpm** (gestor de paquetes)

```bash
# 1. Clonar el repositorio
git clone URL

# 2. Instalar dependencias
pnpm install

# 3. Ejecutar el servidor de desarrollo
pnpm run dev
```

### **Scripts Disponibles**
```bash
pnpm run dev      
pnpm run build    
```
